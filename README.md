# Бесконечная лента мемов

Учебный проект ИТМО: бесконечная имитация социальной ленты на чистом Node.js и Web Streams, без сторонних npm-зависимостей.

Рабочая версия на Helios: <https://se.ifmo.ru/~s506911/meme-feed/>

## Запуск

Нужен Node.js 18 или новее.

```bash
npm start
```

Откройте <http://localhost:3000>.

Для разработки с автоматическим перезапуском сервера:

```bash
npm run dev
```

## Как это устроено

- Серверная async generator-функция `endlessPosts()` создаёт посты без конечного массива.
- `GET /api/feed?limit=6` отдаёт очередную порцию в формате NDJSON через Web `ReadableStream`.
- Компонент `<stream-more>` обрабатывает ответ цепочкой `fetch().body → TextDecoderStream → TransformStream → WritableStream`.
- `IntersectionObserver` запрашивает следующую порцию заранее, когда пользователь приближается к концу ленты.
- Сервер циклически использует 15 узнаваемых шаблонов из открытого API [Memegen.link](https://memegen.link/guide/), а подписи и варианты шуток генерирует отдельно. Даже после первого круга точные подписи не повторяются.
- Текст накладывается клиентом поверх стабильного изображения шаблона: это быстрее и надёжнее, чем каждый раз просить внешний сервис отрисовать новый файл.
- Если Memegen.link недоступен, сервер и клиент используют локальную SVG-заглушку, поэтому лента продолжает работать.
- Node.js-сервер заранее загружает ближайшие изображения и кэширует их в памяти. Это устраняет повторные обращения к внешнему API и ускоряет прокрутку ленты и открытие обсуждений.

## Что сделано

`server.js` раздаёт статические файлы и endpoint `/api/feed`. Бесконечный async generator создаёт публикации по одной, а endpoint ограничивает поток размером запрошенной порции. Посты не хранятся в заранее подготовленном массиве: новые ID и данные создаются во время запроса.

`public/stream-more.js` содержит веб-компонент ленты. Он читает NDJSON постепенно, преобразует каждую строку в объект публикации и сразу добавляет карточку на страницу. Когда нижний индикатор приближается к экрану, `IntersectionObserver` запрашивает следующую порцию.

Интерфейс сделан в нейтральном стиле обычной социальной сети: светлый фон, компактная шапка, реальные имена, простые карточки без рекламного вступления и декоративных технических подписей.

У каждой публикации есть отдельный экран с тематическими комментариями. Имена авторов постов и комментариев открывают их профили. В профиле доступны две вкладки: собственные публикации и репосты.

Кнопка «Добавить мем» открывает форму пользователя **Гарифуллин Искандар**. Можно выбрать локальное изображение, добавить подпись и опубликовать запись. Загруженные файлы хранятся в памяти учебного сервера: после его перезапуска они удаляются.

Дополнительные API-методы:

- `GET /api/posts/:id` — публикация вместе с комментариями;
- `GET /api/profiles/:id` — профиль, его публикации и репосты;
- `POST /api/posts` — загрузка пользовательского мема в JSON с полями `text` и `image`.

## Проверка API

```bash
curl -N "http://localhost:3000/api/feed?limit=3"
```

Ответ содержит три JSON-объекта, по одному в строке. Повторный запрос выдаёт новые посты с новыми ID.
